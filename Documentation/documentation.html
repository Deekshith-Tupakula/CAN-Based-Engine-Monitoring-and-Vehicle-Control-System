Fault Detection: Software Watchdog with Node Error Screens

1. System Overview & Architecture

This project implements an intelligent distributed automotive Electronic Control Unit (ECU) network using three NXP LPC2129 ARM7 microcontrollers communicating over an ISO 11898 compliant CAN 2.0B bus at 250 kbps with active node failure detection and automatic dashboard recovery.

1.1 Distributed ECU Nodes & Fault Supervision

  • Main Telemetry Node (Master Instrument Cluster): Manages the 20×4 LCD digital instrument cluster, samples engine temperature from a DS18B20 1-Wire sensor, supervises CAN response timeouts, and displays dedicated error screens upon node disconnection.
  • Window Glass Control Node (Body Control ECU): Features 8 physical LED levels (P0.0-P0.7) supporting single-tap step increments, continuous press holding, and physical boundary protections.
  • Reverse Alert Node (ADAS / Parking Proximity ECU): Employs a 20-sample trimmed mean filter, digital low-pass filtering, and deadband hysteresis on the Sharp GP2D12 IR sensor (AD0.0 / P0.27).

5. Build & Proteus Simulation Instructions

  1. Keil uVision: Open each node project, verify target device is NXP LPC2129, compile with crystal frequency at 12.0 MHz, and generate .hex files.
  2. Proteus Simulation:
    • Place three LPC2129 microcontrollers and three MCP2551 transceivers.
    • Connect differential pair CANH and CANL across all three nodes with two 120Ω termination resistors.
    • Wire the 20×4 LCD to P0.0–P0.10, DS18B20 to P0.22, LED bar to P0.0–P0.7, and GP2D12 to P0.27.
    • Load the compiled .hex files and test disconnecting any CAN line to verify live node disconnection error alerts.
